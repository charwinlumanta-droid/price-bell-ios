Foreground behavior
Live direct quotes and repeating local sound run while this app stays open.
Leaving the screen, locking the phone, closing it, or losing internet pauses
the session. Reopen and tap Start monitoring. Cached files can reopen the
interface offline; no new live price can be checked while offline.

For locked-screen messages, keep Windows Price Bell monitoring and connect
Telegram there. This web app has no cloud price monitor or Web Push backend.
It never asks you to enter a Telegram bot token.

Data
Targets and History are saved in this site/browser's local storage. Export a
backup before changing the site address or clearing website data. Use one
active Home Screen desk; another window changing saved data pauses/reloads
the current desk, and pre-save checks reject unseen updates.
