How this iPhone version works.

The app has your ICC logo, a trading-style interface, live Deriv/Binance prices, an alert queue, saved history, and local alarm sound. When a target triggers, it leaves Queue and is saved in History before the alarm. Rearm creates a new queued alert while keeping the original history entry.

Keep the app open for direct price alerts. iPhone can suspend a web app when you switch apps or lock the screen. This version cannot continuously watch prices or ring in the background. Use the Windows + Telegram method below for locked-screen messages.

The app folder: price-bell-ios-github. Its index.html, scripts, styles, manifest, logo, and icons folder must stay together.

Before installation: the app needs a stable HTTPS website address. Upload this app folder using the Windows steps below, or use the published URL supplied with your delivery if one has been provided.

Use iOS 15.4 or later, preferably the latest iOS your iPhone supports. Update from iPhone Settings → General → Software Update before installing if needed.

A ZIP or HTML file opened from the iPhone Files app is not the installed app. Hosting supplies the secure address Safari needs. The app stores targets/history on that iPhone; they do not synchronize with Windows or Android.

01 · CHECK THIS ON WINDOWS

Publish the app with GitHub Pages.

If your delivery already includes a tested live app link, open that exact HTTPS link in Safari and skip to the next section. Otherwise follow these steps on Windows. The repository ZIP is the source package; the published website is what you install on the iPhone.

  1. Sign in to the GitHub account that owns the price-bell-ios repository, then open that repository.
  2. Open Settings → Pages. Under Build and deployment, choose GitHub Actions as the source. This repository already contains the publishing workflow; you do not need to add another one.
  3. Open the repository’s Actions tab. Select Test and publish iPhone app.
  4. If no run has started, click Run workflow, choose main, and click the green Run workflow button. Refresh after a few moments.
  5. Open the newest run and wait until both build and deploy show green check marks. The engine tests run before the website can publish. If a step is red, open it to read its message; check the troubleshooting section.
  6. Return to Settings → Pages. Click Visit site or copy the published HTTPS address GitHub displays. It normally looks like https://YOUR-GITHUB-USERNAME.github.io/price-bell-ios/, with your actual account name.
  7. Open that address on Windows and confirm the ICC logo and Price Bell controls appear. Keep the complete repository path and final slash.
  8. Open the same address directly in iPhone Safari. Keep the same account, repository name, and site address for future updates so the phone keeps using the same saved desk.

A website is ready only after publication succeeds. This package does not claim a live URL by itself. Use the real link shown by GitHub after the green deploy job, and verify it opens the app.

If you need to upload the source yourself

Create a repository named price-bell-ios on your own GitHub account. Ordinary free accounts normally need a public repository for Pages. Upload the contents of price-bell-ios-github with index.html at the repository root. Include the full icons, scripts, and hidden .github folders, plus package.json and .nojekyll. The supplied ZIP includes these. Do not upload the generated dist folder, Windows application, user settings, or private tokens. Commit the files to main, then follow the Pages steps above. A GitHub desktop or browser upload that omits .github/workflows/pages.yml cannot run this workflow.

The build publishes a fixed list of app, guide, and icon files. Tests, workflow files, and repository documentation stay in the repository. Your locally entered levels and history are stored on the phone, not in the repository.

02 · DO THIS ON IPHONE

Add Price Bell to your Home Screen.

  1. Open Safari on the iPhone. Enter the app’s published HTTPS address. Use Safari itself rather than an embedded browser inside a messaging app.
  2. Wait for the Price Bell logo and interface to finish loading while internet is connected.
  3. Tap Safari’s Share button — the square with an upward arrow. On some Safari layouts, open the menu first to find Share.
  4. Scroll through the share actions and tap Add to Home Screen. If it is missing, scroll further or use Edit Actions if your iOS version offers it.
  5. Leave the name as Price Bell, then tap Add. If your iOS version shows Open as Web App, leave it enabled.
  6. Return to your Home Screen and tap the new ICC Price Bell icon.
  7. Create your alerts inside this installed app. Safari and a Home Screen web app may use separate storage on some iOS versions, so do not assume targets created in another browser window transferred.
  8. Open Settings and run the alarm test. A tap enables audio; confirm your volume and speakers/headphones.

The Home Screen icon opens the website as an app. No Mac, Xcode, Apple developer signing, or App Store submission is needed for this web-app installation.

The shell can reopen offline after its first successful download. Live price monitoring still needs internet. Queues and history stay on the same browser/site/device. Clearing website data, changing the site’s address, or removing the app may remove access to those records.

Keep a backup of your levels.

Before moving to another address/device or clearing data, open Settings → Export backup and keep the downloaded JSON file. Use Settings → Restore backup in the destination app to choose that file. A backup contains your target levels/history; keep it private.

03 · PROVE YOUR FIRST BELL

Create and test a price alert.

  1. Open the Home Screen app and choose Market.
  2. Choose Deriv or Binance, search/select a supported market, and tap Start monitoring.
  3. Wait for a live number and recent source age. Example symbols are Deriv stpRNG (Step Index) and Binance BTCUSDT (Bitcoin/Tether spot).
  4. Tap the alarm test in Settings if you have not yet enabled and checked sound. Dismiss the test.
  5. Enter a numeric Target price, choose the alert type, and choose the trigger rule.
  6. At or above triggers on a fresh price at least as high as your level. At or below triggers on a price at most as high. Crosses / touches triggers on an exact touch or a fresh move across the level. Above/below can trigger immediately on the next tick when its condition is already true.
  7. Tap Add to queue. Open Queue to see your armed target.
  8. For a simple test, use At or above and a target below the current price. For example, if the current price is 100, a target of 99 should fire on a fresh price of 99 or higher.
  9. When it rings, tap Dismiss. The target should be removed from Queue and listed in History with target, observed price, and trigger time.
  10. Tap Rearm in History to add a fresh queued alert. The original history stays. If its above/below condition still holds, it may ring again on the next tick.

Use the same provider and symbol as your trading chart. The categories label your chosen levels; they do not read open trades or place orders. The app does not support every TradingView market, broker, stock, or futures symbol.

If you close, lock, or leave the app, reopen it and start monitoring again. A move that happened while no fresh prices were being received may be missed. Crossings begin from a new fresh baseline after reconnection.

04 · WHEN IPHONE IS LOCKED

Receive a Windows bell through Telegram.

This is the practical background option included with your existing Windows app. The PC watches prices; Telegram delivers the message to the iPhone.

  1. Install Telegram from the iPhone App Store and sign in.
  2. Open the updated ICC PriceBell Windows desktop shortcut.
  3. In Windows Price Bell Settings, open Telegram settings. Create a bot using the official @BotFather and /newbot, or use your existing bot.
  4. Paste the token into the Windows app, then click Connect automatically.
  5. Open its private bot link on the receiving Telegram account, tap Start, and click Finish connection in Windows.
  6. Click Send Telegram test. Verify it arrives on the intended iPhone account.
  7. In iPhone Settings → Notifications → Telegram, enable notifications and sound. Check your bot conversation is not muted and Focus mode allows it.
  8. Create the price targets in the Windows app and leave it running, awake, and online.
  9. Lock the iPhone and test a deliberately easy Windows target. Verify the Telegram notification.

Configure background targets in Windows. Targets entered only in this iPhone web app do not synchronize to the PC. Telegram delivers a message, not an indefinite repeating iPhone siren. Phone sound follows Telegram, iOS notification, and Focus settings.

No bot token belongs in this website’s files. This iPhone web app does not collect or transmit your Telegram credentials.

05 · TROUBLESHOOTING

If something does not work.

I only have the ZIP / HTML file

Extract it on Windows, publish the static app folder using section 1, then open the actual HTTPS address in Safari. Opening an HTML attachment in Files is not a Home Screen app installation.

Add to Home Screen is missing

Use Safari on the iPhone, open the published website, and use the Share menu. Scroll through its actions. An embedded browser inside another app may not provide this installation action.

The site opens but has no logo or buttons

Upload every file and the icons folder together. index.html must be at the deployment root. Avoid uploading only index.html or adding an extra parent folder above it.

No live price / stale price

Check internet, the provider/symbol, and your device clock. Refresh the market list and start again. Provider availability can vary by region. Cached app files or symbols do not prove current live-price availability.

No sound

Tap the sound test after opening the app. Check phone volume, Bluetooth/headphones, and silent/Focus behavior. iOS may require a user tap to enable browser audio. Keep Price Bell in the foreground.

No alarm after locking or switching apps

iPhone can suspend a web app’s timers and WebSocket connection. Direct alerts require the open app. For locked-screen messages, use Windows + Telegram. This package contains no background monitoring server or web-push delivery system.

My targets disappeared after changing the URL

Browser data is tied to the site’s origin and context. Use the same installed Home Screen app and the same published address. Targets/history do not automatically transfer between hosting domains, Safari, another browser, and the Home Screen app.

How do I update the installed app?

Publish the full updated app folder to the same site. Close its open windows and reopen it with internet connected so the new service worker can activate. Changing the cache version is part of each application release. Recreate the shortcut only if needed; avoid clearing site data just to refresh the interface.
